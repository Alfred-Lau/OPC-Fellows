                                        微信草稿生成

                                        只要贴入或读取正文 Markdown。作者在下方填写，也可到设置里存一份默认作者；标题和简介会在生成时由 AI 根据正文总结。 转 HTML 前会先审查正文：去掉封面图、文首 YAML、排版风格 / 封面图方案 / 备选标题 / 内容验真等策划模块，以及 AI 指引性文案，只留知识正文。 校对正文只做红线词筛查、错别字纠正、去掉没有形成格式的 Markdown 符号，不改表意。 封面只读文档同级 images/ 里的手工图（封面.jpg / 封面.png / cover.jpg），不会自动生成，也不会写进正文。 正文里的本地图片（如 /images/插图.jpg）会按 .md 所在目录或所选配图文件夹解析，先上传到微信再写回正文。 按所选通道（直连微信 API 或扣子工作流）：审查正文 → 校对正文 → 取 token → Markdown 转 HTML → 上传封面与正文图 → 新建草稿，成功后到公众号后台「草稿箱」查看。

                                        正文主文档 · Markdown

                                        文章信息

                                        微信 draft/add 没有官方「声明原创」字段，原创标只能到公众号后台草稿箱手动点。 勾选后会在正文末尾写入「本账号」原创说明（有默认作者则用作者名）；阅读原文用上方链接。

                                        接口与密钥设置（AppID / Secret / 生成通道）

                                        直连模式需要公众号 AppID/AppSecret，且本机出口 IP 需在公众号后台「IP 白名单」内（否则报 40164）；扣子模式额外需要工作流 ID 和 PAT。 敏感信息通过系统安全存储加密保存在本机；也可用环境变量 COZE_TOKEN / WX_APPID / WX_APP_SECRET 覆盖（环境变量优先）。扣子 PAT 在 coze.cn/open/oauth/pats 创建，需具备该工作流运行权限。
