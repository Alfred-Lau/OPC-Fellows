# 增长黑客：实验主人，不抢流量、弹药和账本

左栏新增职业「增长黑客」。它只拥有增长实验、增长环和渠道表。流量快照仍归项目监控官，文案仍归社媒弹药手，账本仍归财务顾问。中栏 6 条职业 Skill；右栏增长台是这些 Artifact 的 Panel。

## 为什么这样

OPC 现在能捞 idea、看站点掉量、写弹药、记账号日记、看 MRR，但没有人负责「这句话该不该扩、这个环能不能复利、这一层漏在哪」。把这些塞进监控官会让 Snapshot 夹带实验；交给弹药手会把文案和假设混成一份真相；做成 Workbench Skill 赋能给任意成员，则和「职业私有 SOP、不做商店」打架。

增长黑客按 Sean Ellis / Balfour 的实验驱动增长来具身：先有可判定的假设，再排渠道、画能复利的环。AARRR 是诊断坐标，不是又一张监控图。

## 边界

| 它做 | 它不做 |
|---|---|
| 开 / 判实验 | 刷新态势、解读流量（监控官） |
| 画增长环、给渠道打分 | 写六平台文案、登记发布（弹药手） |
| 把赢了的实验指针交给弹药手 | 复制 Idea 正文、改管线状态（选品） |
| 判定之后写内核待办 | 手工入账、看 MRR（财务顾问） |
| 诊断哪一层没有在跑的实验 | 把 Snapshot / Ledger 复制进增长台 |

诊断漏斗只读自己的 Artifact。缺流量或营收时，回复里点名去 `@项目监控官` / `@财务顾问`，不直连对方 store。

## Skill（6 条）

| id | 口令 | 效果 | 何时 |
|---|---|---|---|
| `diagnose` | 诊断漏斗 | read | 看各层覆盖、在跑实验、渠道表 |
| `experiment` | 开实验 | write | 写下假设、指标、AARRR 层；可挂 Idea 指针 |
| `verdict` | 判实验 | write | 赢了 / 输了 / 无结论；源关闭则下游停 |
| `loop` | 画增长环 | write | 内容 / 裂变 / 付费 / 销售 / 产品环 |
| `rank` | 排渠道 | write | 试水 / 扩量 / 暂停 / 杀掉，1–5 分 |
| `ship` | 交接弹药 | write | 只传 `ammo:{experimentId}` 指针 |

`/` 菜单和芯片用口令。无 key 时 Trigger 家族匹配兜底；有 key 时走 Skill Route。主对话 implicit；项目里没 @ 只有主成员听见。

## Artifact

**Experiment（增长实验）**
一条可判定的假设。字段：假设、北极星指标、AARRR 层、状态（草稿 / 在跑 / 赢了 / 输了 / 无结论）、可选 `ideaId` / `loopId` / `channelId`。有且仅有一个主人：增长黑客。

**Loop（增长环）**
一条可复利的步骤串，例如「发帖 → GEO → 注册 → 再发」。可挂产品目录指针，不复制产品记录。

**Channel（渠道）**
一个分发面的处置：试水 / 扩量 / 暂停 / 杀掉。不是账号，也不是弹药。

## 允许的 Handoff

- Idea → Experiment（`ideaId`，正文仍在选品）
- 判定之后 → Todo（内核，`experiment:{id}`）
- 赢了的 Experiment → Ammo（`ammo:{experimentId}`，弹药手去装填，增长台不写文案）
- Snapshot / Day Log / Ledger → 诊断时只作「去问谁」的提示，不落指针副本

## 禁止的边

- 诊断漏斗去拉监控快照或 Creem
- 开实验时把 Idea 正文抄进假设
- 交接弹药时生成六平台文案
- 监控刷新、弹药装填、心跳同步夹带实验
- 做成第四个内容职业或「增长市场」

源关闭则下游停：Idea 丢掉之后，挂着它的实验不得假装还活着；只提示源头已关。

## 系统落点

```
雇成员选「增长黑客」
        │
        ▼
Template growth  ──► Module growth（Cordis + manifest）
        │                    │
        │                    ├─ IPC  growth:*
        │                    ├─ 存储  userData/growth.json
        │                    └─ nav   右栏 Panel
        ▼
Agent 增长黑客（singleton，defaultAgentId = growth）
        │
        ├─ 主对话  implicit 走 6 条 Skill
        ├─ 项目里  没 @ 时仅主成员听见
        └─ 今日    必须 @增长黑客 或 /开实验
```

单例：增长台是一份真相，再雇只打开已有成员。禁用模块后成员仍在花名册，状态 `needs-module`，数据保留。

## 考虑过但没选

- 把增长做成监控官子页：Snapshot 会夹带实验，违反 0001。
- 赋能「增长建议」给任意成员：职业边界磨平。
- 一条胖 Skill「做增长」：`/` 菜单失去职业菜单意义。
- 自动按流量掉量开实验：监控刷新不得夹带增长待办。
- 组合模板「增长达人」一次雇出监控+弹药+增长：和自媒体运营达人不同，这三份 Artifact 经常要单独说话，不摊平。
