# 职业私有 Skill 与单主人 Artifact

十个左栏职业加台伴按职业私有 SOP 工作，不做成扣子式技能商店。每个职业 3–6 条 Skill，中栏走 Skill Route；右栏先收编现有 Panel。Artifact 有且仅有一个主人，跨身份只传指针。待办走内核，不占职业名额。

## 为什么这样

对照扣子插件三件套（Skill / Tool / Panel）够用，对照技能市场会把职业边界磨平。现有代码把 Skill 当成 `/` 快捷句、把弹药焊在监控页上、把「写待办」散落在各模块——不先钉主人，后面每加一条跨页功能都会复制第二份真相。

## 允许的 Handoff

- Idea → Ammo（`ideaId`）
- Idea → Experiment（`ideaId`）
- 赢了的 Experiment → Ammo（`ammo:{experimentId}`）
- 已发布的国内 Ammo → Day Log
- Note 或文件路径 → Wx Draft（正文主人不变）
- 任何职业判断之后 → Todo
- Todo 的到点时刻 → Alert（只读）

## 禁止的边

- 监控刷新夹带弹药或社媒待办
- 微信「成交」自动变手工入账
- Idea 直接变成公众号正文
- 诊断漏斗去拉监控快照或账本
- 复制一份下游对象后两边各改各的

源关闭则下游停，不得擅自复活。

## 职业目录

| 职业 | 主 Panel | Skill | 自有 Artifact |
|---|---|---|---|
| 选品策略师 | 选品流 | 扫描痛点、评估 idea、管线改判、立项交接 | Idea、Signal |
| 增长黑客 | 增长台 | 诊断漏斗、开实验、判实验、画增长环、排渠道、交接弹药 | Experiment、Loop、Channel |
| 项目监控官 | 监控态势（无弹药区） | 刷新态势、解读流量、项目健康、页面归因、解读性能 | Snapshot |
| 微信情报官 | 情报四子页 | 今日行动、待回复、商机分流、查人查事、接入体检 | Wechat Action、Reply Draft |
| 邮件整理 | 收件箱 / 查找 / 接入 | 收件箱、分流邮件、查邮件、回信草稿、接入邮箱 | Mail Message、Mail Draft |
| 社媒弹药手 | 独立弹药 Panel | 装填弹药、发布登记、采集互动、复盘热帖 | Ammo、互动指标 |
| 公众号编辑 | 草稿工作台 | 收成草稿、补元数据、复查记录 | Wx Draft |
| 自媒体账号 | 账号台 | 建档账号、记今日发出、采当日数据、关联选材 | Account、Day Log、Material |
| 财务顾问 | 收款台账 | 同步心跳、解读账本、手工入账、支出结算、导出月报 | Ledger Entry（及订阅、手录、支出、结算、事件） |
| 随手记 | 笔记列表 | 记下、找回、升格待办 | Note |
| 台伴 | 无（独立窗，不进左栏） | 到点提醒、打开工作台、稍后消掉 | Alert |

公众号「转稿」是「收成草稿」里的 Workflow，不是 Skill。X 推送是弹药手的扩展 Tool。自媒体运营达人是雇佣快捷方式：一次雇出自媒体账号和社媒弹药手，不是可匹配的第四个内容职业。匹配规则见 [0002](./0002-skill-route-matching.md)。增长黑客的边界见 [0004](./0004-growth-hacker.md)。

## 考虑过但没选

- 技能可挂到任意身份：职业变成插件架，和「不做商店」打架。
- Dashboard 只认关键词：Skill 会退化回今日的 slash。
- Dashboard 自由闲聊：SOP 变成建议，Panel 与中栏会各说各话。
- 交接即复制 / 文件树当权威：和当前模块 json 真相冲突，且对不齐。
- 一条胖 Skill 吃掉整个职业：`/` 菜单失去职业菜单的意义；微信情报官的外部说明书对内仍拆成五条。
