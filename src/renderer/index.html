                文章信息

                微信 draft/add 没有官方「声明原创」字段，原创标只能到公众号后台草稿箱手动点。 勾选后会在正文末尾写入「本账号」原创说明（有默认作者则用作者名）；阅读原文用上方链接。

                接口与密钥设置（AppID / Secret / 生成通道）

                直连模式需要公众号 AppID/AppSecret，且本机出口 IP 需在公众号后台「IP 白名单」内（否则报 40164）；扣子模式额外需要工作流 ID 和 PAT。 敏感信息通过系统安全存储加密保存在本机；也可用环境变量 COZE_TOKEN / WX_APPID / WX_APP_SECRET 覆盖（环境变量优先）。扣子 PAT 在 coze.cn/open/oauth/pats 创建，需具备该工作流运行权限。
